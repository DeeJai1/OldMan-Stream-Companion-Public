# OldMan Stream Companion

Free Windows streaming tools, running locally on your computer.

This is the official public distribution repository. Stable Windows installers
and update packages will be available on the [Releases page](https://github.com/DeeJai1/OldMan-Stream-Companion-Public/releases).

Public downloads are being prepared for launch. Use the
[official website](https://oldmanstreamcompanion.com) for launch information.

## Installing and updating

Once a stable release is published, download its
`OldManStreamCompanion-Setup-X.Y.Z.exe` installer and follow the setup prompts.
Existing installations can check for stable updates inside OMSC. The ZIP and
`.sha256` files are used by the application updater.

## Beta access and support

Beta testing is separate from public stable releases. See
[Beta Access](https://oldmanstreamcompanion.com/beta/) for participation details.
Approved testers receive beta updates through OMSC.

For help, visit the [OMSC Discord community](https://discord.gg/SG4fTGx7cP).
Do not include account tokens, connection credentials or personal settings in
public reports.
